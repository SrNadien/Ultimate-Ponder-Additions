# Botany Pots

One crop, one block, no farmland. A pot takes a soil and a crop and grows it on its own, which makes
it the tidiest farm in the game and the only one that works on a skyblock with no dirt to spare.

Three kinds of pot, and the difference between them is small but worth knowing.

<SubPages />

Which soils and crops exist is data-driven, so a modpack can add, remove or rebalance any of them
without touching the mod.
