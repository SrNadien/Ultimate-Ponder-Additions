# Waxed Botany Pot

Decoration. Nothing more.

<GameScene zoom="5" interactive={true}>
  <ImportStructure src="../assets/botanypots/pots.snbt" />
  <BlockAnnotation x="3" y="2" z="2" color="#5f6caf">Waxed Botany Pot</BlockAnnotation>
</GameScene>

A waxed pot always renders its crop fully grown, and it never ticks. No growth, no drops, no logic
running behind it.

The upside is that it costs nothing. Fill a greenhouse with a hundred of them and the server will
not notice.

Use them for the garden you want to look at, and ordinary pots for the one you want to harvest.
