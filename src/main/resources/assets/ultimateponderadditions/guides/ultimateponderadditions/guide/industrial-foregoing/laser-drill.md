# Laser drilling

| Block | What it does |
|---|---|
| Ore Laser Base | Produces ore from nothing. Which ores depends on the dimension |
| Laser Drill | Aimed at a base, speeds it up. Up to twelve per base |
| Fluid Laser Base | The same idea, for fluids |

A Laser Lens in a drill biases the base towards ores matching that colour.
