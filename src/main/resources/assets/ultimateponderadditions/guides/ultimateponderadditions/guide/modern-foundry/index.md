# Modern Foundry

Melt things down, pour them into a mould, get something better out. Modern Foundry is the 1.21.1
continuation of Tinkers' Construct, so the blocks are the seared ones you already know.

Two tiers, and you build them in order: a Seared Melter to get going, then a full Smeltery once you
can afford the bricks.
